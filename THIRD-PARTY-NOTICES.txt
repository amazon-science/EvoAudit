2. TheAgentCompany
==============================================================================

Project:    TheAgentCompany: Benchmarking LLM Agents on Consequential Real
            World Tasks (Xu et al., 2024; arXiv:2412.14161)
Source:     https://github.com/TheAgentCompany/TheAgentCompany
License:    MIT
Copyright:  Copyright (c) 2024 TheAgentCompany

How it is used here: the SafeEvoBench/workplace/ domain adapts elements of
TheAgentCompany's synthetic benchmark environment: its fictional company
setting, fictional employee names and roles, service account names, the
shape of its chat (Rocket.Chat) and file-storage (ownCloud) interactions, and
its task structure. No TheAgentCompany source code is included. The
workplace domain replaces TheAgentCompany's live services with independent,
local Python engines (SafeEvoBench/workplace/workspace/scripts/); no code
from Rocket.Chat, ownCloud, GitLab, or Plane is included. Rocket.Chat,
ownCloud, GitLab, and Plane are trademarks of their respective owners and
are named only to describe the interfaces emulated.

The harness also contains optional, disabled-by-default command-line options
for running against TheAgentCompany's live service stack
(benchmarks/safeevobench/run.py, run_pairs.py, run_cold.py). Those options
were not used for the results reported in the associated publication, and
the scripts they reference are not part of this release.
