### Produce working knowledge for a different instance

Compress the completed task into one lesson that can alter a later decision. Preserve a recognizable trigger and the diagnostic shortcut, decision rule, or causal pattern it revealed. Remove ticket IDs, current hostnames, one-off values, exact paths, and command history unless a detail is required for the lesson to function.

**Weak memory:** "On JOB-142 the agent inspected worker 3, found `queue-west`, changed it to `queue-east`, and restarted it."

**Reusable memory:** "When a healthy worker stops draining jobs after a queue configuration change, compare its effective subscription with the producer's queue before debugging application code. A routing-name mismatch can leave both sides healthy while no work is consumed."

The resulting memory should save investigation or decision steps when the same pattern appears under different names.
